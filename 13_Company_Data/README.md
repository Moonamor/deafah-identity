# بيانات الشركة العامة — مجموعة الضيافة العالمية

> **لا تعدّل هذه الملفات هنا.** تتولد تلقائياً من قاعدة المعرفة الخاصة (المصدر الوحيد)، وأي تعديل يدوي يُمسح في المزامنة التالية. التعديل يكون في قاعدة المعرفة، والمزامنة تحدّث هذا المجلد.

في هذا المجلد الحقائق **المعتمدة القابلة للنشر فقط**: الأسماء، والتصنيف، وعدد الغرف، والمسافات، والعناوين، والخدمات، والقيم، والتواصل الرسمي. القيم غير المؤكدة غير موجودة هنا أصلاً، فما يظهر هنا يصح نشره.
